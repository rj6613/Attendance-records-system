STUDENT ATTENDANCE SYSTEM  -  HCI Individual Semester Project
=============================================================

HOW TO RUN (no installation, no internet needed)
1. Unzip this folder.
2. Double-click  index.html  (opens in Chrome / Edge / Firefox).
3. Sign in with the demo account:
      Email:    teacher@school.edu
      Password: attend123

SCREENS
1. Login            (index.html)
2. Dashboard        (dashboard.html)
3. Mark attendance  (attendance.html)
4. Students         (students.html)   + Add-student form
5. Student profile  (student.html)
6. Reports          (reports.html)    + CSV export / print

NOTES
- Data is stored in your browser (localStorage). Sample data for 3 classes
  and 30 students is created automatically on first run.
- To reset all data: open the browser console and run  localStorage.clear()
- Folders: css/ (styles), js/ (logic + data), screenshots/ (all screens),
  docs/ (project report PDF).
